Lists:
Items ki list banane ke liye use hota hai.Types: Ordered List (ol), Unordered List (ul).
links:
Ek page ko dusre page ya website se connect karne ke liye use hota he. Tag: a href="URL/file location"
Images:
Website me images show karne ke liye use hota hai. Tag: img href="file location"
Tables:
Data ko rows aur columns me dikhane ke liye use hota he. Tags: table, tr, td.
Forms:
User se input lene ke liye use hota hai. Example: login form, signup form.
